High-Functioning Client Technique

RACE

⏱ Session technique for resistant clients · ✓ 4 steps in sequence
Reflect → Agitate → Concretize → Elicit
Overview

四个步骤

高功能来访者习惯理智化（intellectualize）。RACE 不靠治疗师去说服，而是让来访者自己感受到不一致，自己说出需要改变的地方。

R
Reflect
复述

mirror back what they said

A
Agitate
制造不一致感

highlight the gap between what they say and what they do

C
Concretize
拉到具体情境

pull them into a specific real situation

E
Elicit
让他自己说需要

let them voice their own need for change

📌 抓住感觉

说完后你什么感觉？现在什么感觉？到 core experience 时继续 explore。

"你感觉……" 太长就 rephrase，重点永远是最后一句。

为什么对高功能来访者有效：他们擅长分析和讲故事，RACE 把他们从"讲道理"拉回"当下的感受"，不靠治疗师下结论，而是让不一致自己浮出水面。
Deep Dive

四个字母，逐个拆解

点开展开每一部分的完整层次与例句。

R Reflect（复述）— 不只是重复内容，有 4 个层次
1 · Rephrase（重述内容）
病人："我不想依赖别人。"你："你希望更独立一点。"
2 · Reflect Feeling（反映情绪）
病人："每次要找别人帮忙我都很烦。"你："那种感觉让你很挫败。"
3 · Reflect Meaning（反映意义）
病人："我讨厌依赖别人。"你："对你来说，依赖别人好像代表自己不够好。"
4 · Reflect Core Theme（反映核心主题）
病人："我总是需要别人。"你："你好像一直在努力证明自己可以靠自己。"
这个已经接近治疗层面了。
A Agitate（制造不一致）— A 不是挑战（challenge），是把矛盾放到桌上
认知 vs 行为
"你说咨询不会有用，但你还是来了。"
目标 vs 现实
"你很想独立，但现在好像常常不得不依赖别人。"
希望 vs 恐惧
"你很希望跟别人靠近，但又很怕自己成为负担。"
价值观 vs 自我评价
"你会照顾很多人，但对自己却非常严厉。"
这类 A 通常威力很大。
C Concretize（具体化）— 从头脑回到现实
找例子
"最近一次是什么时候？"
找情绪
"当时你是什么感觉？"
找身体
"你身体哪里最有感觉？"
找画面
"那一幕是什么样子？"
找第一反应
"脑子里第一句话是什么？"
找意义
"当时这件事对你意味着什么？"
C 不只是事件。它是把抽象拉回体验（experience）。
E Elicit（让他说需要）— 帮病人把隐含的需求说出来
很多病人只会说"我不要这样"，不会说"我想要什么"。
而且 E 通常不是问一次就出来的——表层答案很正常，换个问法再问，或退回 C 再具体化一轮，来回几次才会真正触到核心。
想改变什么
"如果可以有一点不一样，你希望哪里先改变？"
想得到什么
"你最希望从咨询得到什么？"
想相信什么
病人："我很没用。"你："如果不用相信自己没用，你希望自己相信什么？"
内心渴求什么
病人："我不想依赖别人。"你："那个很想独立的部分，真正渴望的是什么？"
常见答案：自由 / 安全感 / 被尊重 / 被爱 / 不要成为负担。到这里就接近治疗核心了。
Demonstrations

完整示范

同一套 RACE，在不同 insight 层级的来访者身上，走法完全不同。

🔁 示范是压缩版

下面的对话为了讲清楚步骤而压缩了。现实中 E 很少一次就问出核心——常见的是问了只得到表层答案，需要换句话重问，或退回 C 再具体化一轮，来回好几次才会真正触到核心。一次没反应不代表方向错了，继续走就好。

示范一 · High Insight

R → A → C → C → E
来访者
我知道应该放下，但就是放不下。
R
理智上接受了，情绪上还没有。
A
一年过去了，这件事似乎仍然影响着你。
C
最近一次想到她是什么时候？
来访者
上周经过以前一起吃饭的餐厅。
C
当时你停下来了吗？脑子里出现什么画面？
来访者
想到以前她坐在我对面。
E
那一刻最痛的部分是什么？
来访者
我觉得再也不会有人那样爱我了。
核心浮现 — 问题不是前女友，而是："我不相信自己还值得被爱。"
RACE 最强的地方：从故事 → 矛盾 → 具体场景 → 核心意义。高功能来访者会一直停留在故事和分析层面，RACE 就是把他往下挖。

示范二 · Low Insight

R → C → C → C → C
来访者
都是我妈的问题。
R
你觉得妈妈给你很大压力。
A
但你好像也因此一直很痛苦。
C
上次跟妈妈冲突是什么时候？
E
这件事对你意味着什么？
来访者
不知道…… 反正就是她有问题。没什么。
Low insight 常见回答是"不知道 / 没什么" — 直接卡住，因为 Elicit 需要 mentalization、self-awareness、emotional vocabulary，很多 low insight client 这些能力还没建立。
Low Insight 策略：R → C → C → C → C，不断具体化，先建立觉察：
  • "她哪里让你生气？"
  • "当时她说了什么？"
  • "你身体有什么反应？"
  • "你后来做了什么？"
  • "你希望她怎么做？"
Stuck Point · 专题

"有用"卡点 — 从 C 卡住到 E

最常见的卡点触发句：来访者说"这个方法有用 / work"。这本身就是一种理智化防御——用"有效"关闭情绪探索。拆解方式如下。

A 的方向 — 不用额外制造，矛盾已经摆在桌上： 如果真的"有用"，来访者为什么还要谈这件事、还要来做治疗？"有用"和"还在这里"本身就矛盾。
  • "如果这个方法真的都有用，是什么让你今天还是想聊这个？"
  • 或抓不一致："你说'有用'的时候声音很平，但刚刚讲到这件事，你皱了一下眉。"
C 的方向 — 这正是你已经想到的那一步： "有用"是一个概括性判断，C 的任务就是拆穿概括、找反例。
  • "有没有一次，这个方法没用？"
  • "上一次它失灵，是什么时候？"
  • "什么情况下最容易失灵？"
找到那个具体时刻后，别停在"有一次没用"这句话上——继续用 C 的六个抓手（情绪／身体／画面／第一反应）往下挖那个瞬间。
E 的方向： 在"失灵"的那个具体时刻里问"当时真正需要的是什么"——这通常就是"有用"这个防御一直在挡住、没被说出来的需求。

示范三 · "有用"卡点

R → A → C → C → E
来访者
我一直靠让自己很忙来处理压力，这个方法很有用。
R
忙起来，好像真的能把压力压下去。
A
如果真的都有用，是什么让你今天还是想聊这个？
来访者
……可能因为最近有点撑不住了。
C
最近一次这个方法没用，是什么时候？
来访者
上周日，家里没什么事让我忙，我一个人在家，突然觉得很不安。
C
那天你身体有什么感觉？脑子里出现了什么？
来访者
胸口很闷，一直在想是不是哪里没做好。
E
那天最需要的是什么？
来访者
……可能只是希望有人能告诉我，我不用一直做才有价值。
核心浮现 — 忙碌不是压力管理工具，而是在逃避："停下来就没有价值" 的恐惧。

最短可说版 — "有用"卡点

A"如果真的都有用，是什么让你还想说这个？"
C"最近一次没用 / 失灵是什么时候？当时身体、脑子里出现了什么？"
E"那次真正需要的是什么？"
Judgment

判断标准 — 什么时候可以进 E

✅ 可以开始 E
"我觉得自己被忽视了。"
"我害怕失败。"
"我其实很失望。"
❌ 继续 C，不要急
"不知道。"
"没事。"
"反正就是烦。"
Insight Levels

三种 Insight Level 路径

High insight
R→ A→ C→ E
一次走完整套
Moderate insight
R→ A→ C→ E
需要很多辅助（多轮 C 铺垫）
Low insight
R→ C→ C→ C→ C
先培养观察能力，E 很后面才出现
Meta Insight

但其实这可能正是主题

如果一个来访者来了 5 次都在说 "我不知道我要什么" ——

那可能不是治疗卡住，那可能就是他的核心困境本身。

示范

R
你花了很多时间想弄清楚自己到底要什么。
A
但好像越努力弄清楚，反而越不确定。
C
最近一次你又陷入这种犹豫是什么时候？
E
如果有一天你不用百分之百确定才能行动，会发生什么？
Quick Script

最短可说版

如果下次又卡在"不知道要什么"：

R"你已经想了很久，还是不知道自己真正需要什么。"
A"但好像越努力想明白，反而越卡住。"
C"最近一次你被这个问题困住是什么时候？"
E"如果暂时不用找到正确答案，你现在最在意的是什么？"
